**CowAgent** is your own open-source personal AI agent. It plans tasks proactively, uses tools, skills and MCP, and gets to know you over time through long-term memory, a knowledge base and self-evolution.

CowAgent is multi-model, multi-channel and multi-agent. Plug in any major LLM provider, assemble a team of agents, and reach it from the Web and major IM platforms, running 24/7 on your computer or server. It's a ready-to-use assistant and an open, extensible Agent Harness.

## Core Capabilities

<CardGroup cols={2}>
  <Card title="Autonomous Task Planning" icon="brain" href="/intro/architecture">

  </Card>
  <Card title="Long-term Memory" icon="database" href="/memory/index">
    Three-tier architecture (context → daily → core), automatic Deep Dream distillation, hybrid keyword + vector retrieval.
  </Card>
  <Card title="Personal Knowledge Base" icon="book" href="/knowledge/index">
    Auto-curates structured knowledge into a Markdown wiki, builds an evolving knowledge graph with visual browsing.
  </Card>
  <Card title="Self-Evolution" icon="seedling" href="/memory/self-evolution">
    Reviews conversations automatically to improve skills, follow up on unfinished tasks, and consolidate memory and knowledge, growing through everyday use.
  </Card>
  <Card title="Skills System" icon="puzzle-piece" href="/skills/index">
    A complete skill creation and execution engine. Install from Skill Hub or generate custom skills via natural-language conversation.
  </Card>
  <Card title="Tool System" icon="wrench" href="/tools/index">
    Built-in file I/O, terminal, browser, scheduler, memory retrieval, web search, and more — with native MCP integration.
  </Card>
  <Card title="Command System" icon="terminal" href="/cli/index">
    Terminal CLI and in-chat commands for process management, skill installation, configuration, and context inspection.

## Quick Start

Run one of the commands below to install, configure, and start CowAgent in a single step:

<Tabs>
  <Tab title="Linux / macOS">
    ```bash
    bash <(curl -fsSL https://cdn.link-ai.tech/code/cow/run.sh)
    ```
  </Tab>
  <Tab title="Windows (PowerShell)">
    ```powershell
    irm https://cdn.link-ai.tech/code/cow/run.ps1 | iex
    ```
  </Tab>
  <Tab title="Docker">
    ```bash
    curl -O https://cdn.link-ai.tech/code/cow/docker-compose.yml
    docker compose up -d
    ```
  </Tab>
</Tabs>

Once started, open `http://localhost:9899` to access the **Web console** — the unified place to chat, configure providers, connect channels, and install skills.

You can also use the desktop client (macOS / Windows), which bundles the Agent runtime: [download it](https://cowagent.ai/download/) and it's ready to use.

If you'd rather not deploy anything or collect model keys, [try it online](https://cloud.cowagent.ai): a dedicated instance in your browser with built-in models, online 24/7. See [CowAgent Cloud](/guide/cloud) for details.
