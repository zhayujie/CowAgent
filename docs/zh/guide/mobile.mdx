CowAgent App 目前处于**公开测试**阶段，各应用市场持续上架中。支持 iOS、Android 与鸿蒙，适配手机与平板。有两种使用方式：

- **在手机上运行**：Agent 运行在这台手机上，数据保存在手机本地，授权后可以使用日历、通讯录、相册、位置等手机能力。
- **连接电脑**：扫码连接电脑、服务器或云端实例上的 CowAgent，在手机上使用它的全部能力，包括运行命令、读写文件和操作浏览器。

两种方式可以随时在侧边栏中切换。

**下载地址**：[cowagent.cn/download](https://cowagent.cn/zh/download/#mobile)

## 在手机上运行

1. 首次打开 App，选择「在手机上运行」，点击「下一步」。
2. 在聊天页点击「配置模型」卡片上的「去配置」，填入模型厂商的 API Key（如 DeepSeek、通义千问、CowAgent 等）并保存。
3. 回到聊天页即可开始对话。

这种方式下，对话、记忆、知识库等数据都保存在手机本地，对话内容只会发送给你配置的模型厂商。手机上没有命令行和浏览器，Agent 不提供命令执行和浏览器操作，计算与文件处理改用内置 Python；需要完整能力时，请连接电脑使用。

### 手机能力

在手机上运行时，Agent 可以调用以下手机能力，每次操作前都会询问，也可以设为「始终允许，不再询问」：

| 能力 | 说明 |
| --- | --- |
| 打开应用和链接 | 打开网页或其他应用，发起导航、拨号、短信和邮件，由你在对应应用中完成 |
| 获取位置 | 读取当前位置，用于查附近、看天气和导航 |
| 日历 | 查看日程，添加日程和提醒 |
| 通讯录 | 按名字查找联系人的电话和邮箱 |
| 选择照片 | 由你从相册选择照片交给 Agent，只分享选中的照片 |
| 分享文件 | 打开系统分享面板，把文件发送到其他应用 |
| 设备状态 | 查看电量、网络、存储空间、省电模式等状态 |
| 运行 Python | 计算、数据处理与文件转换（CSV / Excel / PDF 等），也可运行技能中的脚本 |

首次使用某项能力时，系统会请求对应权限，各项权限的状态可在「设置 → 应用权限」中查看。设为始终允许的操作，可以在对话中该步骤下方点击「改为每次询问」恢复询问。

### 通知与定时任务

App 在后台时，回复完成和定时任务的结果会通过系统通知送达，点击通知直接进入对应会话。在手机上创建的定时任务和提醒由系统按时触发，无需保持 App 在前台。

## 连接其他设备

连接后，在手机上使用的是对方设备上的 Agent，对话和数据都保存在对方设备上。可以连接自己部署在电脑或服务器上的 CowAgent，也可以连接云端实例。

### 连接电脑或服务器

**前提条件**：

- 对方的 CowAgent 版本为 2.3.0 及以上。
- 手机能访问到对方：一般是连接同一个 Wi-Fi，或对方有公网可访问的地址。服务器暴露公网端口时，建议设置访问密码并配置安全组。
- 对方不能只监听本机（`127.0.0.1`），可在「配置 → 集成配置 → 访问地址」中修改。

**连接步骤**：

1. 在电脑端的 CowAgent 中打开「配置 → 设备管理」，点击「让其他设备连接我」，生成配对二维码。服务器上也可以运行 `cow pair` 获取配对码。
2. 在 App 中选择「连接电脑」（首次打开时），或在侧边栏的设备切换中选择「扫码连接」。
3. 扫描二维码，确认后即可使用电脑上的 Agent。

<Frame>
  <img src="https://cdn.link-ai.tech/doc/devices-pair-zh.png" alt="生成配对二维码" width="800" />
</Frame>

无法扫码时，也可以选择「输入地址连接」，填写对方的地址和配对码。配对码 5 分钟内有效，只能使用一次。连接成功后，可以在侧边栏中随时切换「本机」和已连接的设备。

详细说明见 [设备管理](/zh/guide/devices)。

### 连接云端实例

没有电脑或服务器时，可以连接 [云端托管](/zh/guide/cloud) 的实例：在云端控制台的实例卡片右上角「···」菜单中点击「设备」，用 App 扫描弹出的配对二维码即可。云端实例有公网地址，手机不受网络环境限制，随时随地都能使用。

## 主要功能

- **对话**：支持流式回复、语音输入、图片与文件附件，两个会话可以同时回复；回复可随时停止，中断的回复可以继续生成，也可以重新生成回复或编辑已发送的问题。
- **文件**：其他应用中的文件和文字可以直接分享到 App 中，对话中的文件也可以分享到其他应用；文件在 App 内下载，支持断点续传。
- **管理**：智能体、技能、MCP、知识库、记忆、定时任务、通道、访客页面、模型配置等，与 Web 控制台保持一致。
- **界面**：支持中英文、浅色与深色模式，适配 iPad 与平板的横竖屏和分屏。

## 更新

- **iOS**：有新版本时 TestFlight 会推送通知，在 TestFlight 中点击「更新」即可。
- **Android**：有新版本时 App 会自动弹出更新提示，下载完成后校验安装包并交给系统安装；也可以在「设置 → 版本更新」中手动检查。
- **鸿蒙**：有新版本时在华为应用市场中更新。

## 常见问题

**扫码后提示连接不上？**

请确认手机和电脑在同一网络、电脑上的 CowAgent 正在运行，且没有只监听本机。如果提示没有响应，可能是被电脑的防火墙拦截。

**提示版本过旧？**

App 需要对方的 CowAgent 为 2.3.0 及以上版本，请先 [升级](/zh/guide/upgrade)。

**提示需要先登录？**

对方前面有一层登录网关（如反向代理上的身份认证），App 无法用配对码直接连接，需要关闭该网关或为 CowAgent 单独开放访问。
