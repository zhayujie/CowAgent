不想自己准备服务器和模型 Key 时，可以直接在云端运行 CowAgent。每个云端实例都是一个完整的 CowAgent，与源码部署、桌面客户端使用同一套开源代码，Web 控制台、技能、记忆和通道的用法完全一致。

## 特点

- **专属实例**：每个实例运行在独立隔离的环境中，拥有自己的工作空间、记忆与技能。
- **内置模型**：已接入 [CowAgent 模型服务](/zh/models/cowagent)，对话、图像、语音、向量和联网搜索开箱即用，无需自备 API Key；也可以在「模型管理」中换成其他厂商。
- **持续在线**：7×24 小时运行，关掉电脑后定时任务和通道消息照常处理。

## 开始使用

1. 登录控制台：中国大陆用户访问 [cloud.cowagent.cn](https://cloud.cowagent.cn)（支持手机号登录），其他地区访问 [cloud.cowagent.ai](https://cloud.cowagent.ai)。两个站点的账号互不通用。
2. 选择套餐后，在「实例」页面新建实例。
3. 点击「打开」进入实例的 Web 控制台，即可开始对话，或接入微信、飞书等通道、安装技能。

## 如何选择

| | 源码部署 | 桌面客户端 | 云端托管 |
| --- | --- | --- | --- |
| 运行位置 | 自己的电脑或服务器 | 本机 | 云端独立实例 |
| 模型配置 | 自行配置 | 自行配置 | 已内置，也可自行配置 |
| 在线时间 | 取决于机器 | 电脑开机时 | 7×24 小时 |
| 适合 | 二次开发、完全掌控 | 个人本地使用 | 免运维、持续在线 |

三种方式可以组合使用，例如在本机用桌面客户端处理日常事务，同时在云端运行一个持续在线、接入聊天通道的助理。
