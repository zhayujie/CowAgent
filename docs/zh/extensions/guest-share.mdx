> 把 Agent 分享成独立的对话页面，或嵌入到自己的网站，适合做产品咨询、文档问答、客服等场景。访客打开链接即可对话，无需登录。

访客页面上的 Agent 与你日常使用的 Agent 相互独立：它只能使用你为这个页面开放的工具、技能和参考资料，看不到你的记忆、对话和工作空间。

## 开启

在「配置 → 集成配置 → 访客页面」中打开开关。

- **需要先设置控制台密码**。访客页面与控制台共用一个端口，未设置密码时访客链接不可访问，设置后自动生效。
- **服务需要能被外部访问**，部署方式参考 [Web 控制台](/zh/channels/web)。如果通过域名或公网 IP 访问，在同一页的「访问地址」中填写对外地址，分享链接和嵌入代码会使用这个地址。

## 创建页面

点击「新建访客页面」，填写后保存即可生成链接。

### 基本信息

名称、模型、欢迎语和引导问题。模型不选时使用全局默认模型；引导问题显示在欢迎页，访客点击即可提问。

### 外观

图标和主题色，用于访客页面和嵌入窗口的入口按钮。

### 访问控制

- **访问密码**：开启后访客需要输入密码才能使用。
- **每人每日提问**：按浏览器区分访客，默认 100 次，填 0 表示不限制。
- **有效期**：到期后链接自动失效，不填则长期有效。

### 更多设置

- **可用工具**：读写文件、搜索文件、发送文件、联网搜索、读取网页、图片理解和当前时间，新建页面默认全部开启。访客页面不提供执行命令的能力。
- **技能**：从已安装的技能中选择。依赖命令或脚本的技能无法在访客页面使用，不会出现在列表中。
- **参考资料**：Agent 可以查阅的目录，只读。可以直接选择知识库或其中某个分类，也可以填写其他目录。每项可以附一句说明，例如「产品文档，回答功能和价格问题时查阅」，帮助 Agent 判断什么时候去查。
- **访客规则**：会写入 Agent 的系统提示词，用来说明它的身份、服务范围和回复风格。
- **页脚**：页面底部的文字和链接，可以修改或清空。

## 分享与嵌入

在页面列表中复制链接即可分享，链接格式为 `https://<访问地址>/share/<token>`。

嵌入网站时，点击页面的「嵌入网页」，先在「允许嵌入的网站」中填写你的网站地址（如 `https://example.com`），再把代码放到网页的 `<body>` 中，页面右下角会出现对话入口。窗口右侧可以直接预览嵌入效果。

```html
<script src="https://agent.example.com/assets/guest/embed.js"
  data-share-url="https://agent.example.com/share/<token>"
  data-title="在线咨询"
  defer></script>
```

如需调整，可以加上 `data-color` 设置入口按钮的颜色，或用 `data-position="left"` 把入口放到左下角。

## 管理页面

- **访客记录**：按访客查看每一段对话。
- **重置链接**：生成新链接，旧链接和嵌入代码立即失效。
- **断开所有访客**：所有访客需要重新进入（设有密码的页面需重新输入密码），之前的对话不再对他们显示。
- **停用 / 启用**：停用后链接暂时无法使用，正在进行的回复会被中止。
- **删除**：删除页面、链接和全部访客记录，无法恢复。

## 安全说明

- 访客的 Agent 只能访问当前对话的临时目录、选中的参考资料和技能，看不到真实路径，也无法跳出这些目录。
- 不能执行命令；联网工具只能访问公网，本机和内网地址都会被拦截。
- 页面配置保存在 `~/cow/guests/<页面 ID>/`，也可以让你的 Agent 帮忙修改。放宽权限的改动，如增加工具或参考资料、开启联网、取消密码，需要在控制台点击「确认生效」后才会生效。
