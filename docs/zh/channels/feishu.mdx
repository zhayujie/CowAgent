> 通过飞书自建应用接入 CowAgent，支持单聊与群聊（@机器人），使用 WebSocket 长连接模式，无需公网 IP，支持流式打字机回复、语音消息收发。

<Note>
  接入需要是飞书企业用户且具有企业管理权限。
</Note>

## 一、接入方式

### 方式一：扫码一键接入（推荐）

启动 CowAgent 后，可以在终端扫码创建，也可以在 Web 控制台的 **通道 → 接入通道 → 飞书** 中扫码创建。飞书返回扫码人 Open ID 时，CowAgent 自动将其加入本次接入实例的 Owner 名单。


<img src="https://cdn.link-ai.tech/doc/20260505181126.png" width="800"/>


<Note>
  1. `lark-oapi` 依赖版本需要 >=1.7.1
  2. 扫码创建出的应用会自动预置全部所需权限（消息收发、卡片读写、群聊事件等）和事件订阅，无需到开发者后台手动配置。
</Note>


### 方式二：手动创建接入

需要先在飞书开放平台创建自建应用并配置权限，再通过 Web 控制台或配置文件接入。

**步骤一：创建应用**

1. 进入 [飞书开发平台](https://open.feishu.cn/app/)，点击 **创建企业自建应用**：

<img src="https://img-1317903499.cos.ap-guangzhou.myqcloud.com/docs/feishu-hosting-create-app.jpg" width="500"/>

2. 在 **添加应用能力** 中，为应用添加 **机器人** 能力：

<img src="https://img-1317903499.cos.ap-guangzhou.myqcloud.com/docs/feishu-hosting-add-bot.jpg" width="800"/>

3. 在 **权限管理** 中，将以下权限粘贴到输入框，全选并 **批量开通**：

```
im:message,im:message.group_at_msg,im:message.group_at_msg:readonly,im:message.p2p_msg,im:message.p2p_msg:readonly,im:message:send_as_bot,im:resource,cardkit:card:write
```

<img src="https://cdn.link-ai.tech/doc/feishu-hosting-add-auth2.png" width="800"/>

4. 在 **凭证与基础信息** 中获取 `App ID` 和 `App Secret`：

<img src="https://img-1317903499.cos.ap-guangzhou.myqcloud.com/docs/feishu-hosting-appid-secret.jpg" width="800"/>

**步骤二：接入 CowAgent**

<Tabs>
  <Tab title="Web 控制台">
    打开 Web 控制台，选择 **通道** 菜单，点击 **接入通道**，选择 **飞书**，切换到「手动填写」Tab，输入 App ID 和 App Secret，点击接入即可。
  </Tab>
  <Tab title="配置文件">
    在 `config.json` 中添加以下配置后启动程序：

    ```json
    {
      "channel_type": "feishu",
      "feishu_app_id": "YOUR_APP_ID",
      "feishu_app_secret": "YOUR_APP_SECRET",
      "feishu_stream_reply": true
    }
    ```

    | 参数 | 说明 | 默认值 |
    | --- | --- | --- |
    | `feishu_app_id` | 飞书应用 App ID | - |
    | `feishu_app_secret` | 飞书应用 App Secret | - |
    | `feishu_owner_open_ids` | 可选，当前飞书应用的 Owner Open ID 列表 | `[]` |
    | `feishu_private_memory_mode` | 实例的私聊记忆模式 | `owner_workspace` |
    | `feishu_stream_reply` | 是否开启流式打字机回复 | `true` |
    | `feishu_detailed_card` | 流式回复是否使用详细卡片（工具调用、思考过程、耗时展示）；关闭时用普通打字机卡片 | `true` |
  </Tab>
</Tabs>

**步骤三：发布应用**

1. 启动 Cow 项目后，在飞书开放平台点击 **事件与回调**，选择 **长连接** 模式并保存：

<img src="https://cdn.link-ai.tech/doc/202601311731183.png" width="600"/>

2. 点击 **添加事件**，搜索 "接收消息"，选择 **接收消息 v2.0** 并确认。

3. （可选）在 **回调** 中添加 **卡片回传交互**（`card.action.trigger`），以启用 `/tasks` 定时任务管理命令；添加 **撤回消息**（`im.message.recalled_v1`）事件，以支持撤回消息取消任务功能。

4. 点击 **版本管理与发布**，创建版本并申请 **线上发布**，在飞书客户端审核通过：

<img src="https://cdn.link-ai.tech/doc/202601311807356.png" width="600"/>

## 二、功能说明

| 功能 | 支持情况 |
| --- | --- |
| 单聊 | ✅ |
| 群聊（@机器人） | ✅ |
| 文本消息 | ✅ 收发 |
| 图片消息 | ✅ 收发 |
| 语音消息 | ✅ 收发 |
| 引用回复 | ✅ 引用文本与富文本上下文 |
| 流式回复 | ✅（通过 `feishu_stream_reply` 配置控制，默认开启） |
| Markdown 卡片 | ✅ 静态卡片与流式最终态会将远程图片上传到飞书 |
| 详细卡片 | ✅ 工具调用、思考过程与耗时展示（`feishu_detailed_card` 控制，默认开启） |
| 定时任务操作卡 | ✅ `/tasks` 查看、启用、停用与删除 |

<Note>
  流式回复需要机器人具备 `cardkit:card:write` 权限（一键创建已默认开通），且接收方飞书客户端版本 ≥ 7.20。低版本客户端会显示升级提示，权限或版本不满足时自动降级为普通文本回复。
</Note>

## 三、使用

完成接入后，在飞书中搜索机器人名称即可开始单聊对话。

如需在群聊中使用，将机器人添加到群中，@机器人发送消息即可。

私聊发送 `/tasks`，或在群聊中 @机器人并发送 `/tasks`，即可管理属于当前会话的定时任务。

### 成员档案与记忆隔离

在 Web 控制台或桌面端的「手动填写」页，可以为每个机器人保存多个 Owner，填写同一飞书应用的 `open_id`（`ou_...`），用逗号分隔。手动接入可以**查询飞书应用所有者**，查到后点击**采用为 Owner**，再保存设置。查询需要应用已开通 `application:application:self_manage` 或 `admin:app.info:readonly`。扫码注册拿到扫码人 Open ID 时自动绑定到本次接入的实例，缺字段时仍可接入。

Owner 名单和私聊记忆模式写入 `<agent_workspace>/agents/team.json` 对应实例的 `credentials`。启动迁移按 `config.json` 的原 App ID 查找唯一匹配实例，已有名单优先，包括空名单。保存实例后清理全局旧字段。匹配不明确时保留旧配置供人工核对。

旧版单 Agent 安装如果还没有 `team.json`，升级时会新建该文件并写入飞书配置。钉钉等其他旧频道仍从 `config.json` 读取配置。

- `owner_workspace`（默认）：名单内的 Owner 使用工作区根目录的 `USER.md`、`MEMORY.md` 和每日记忆，其余用户各自隔离。空名单时所有人按人隔离。
- `per_user`：所有私聊用户各自隔离，包括 Owner。
- `shared`：所有有有效身份的私聊用户共用工作区档案和记忆。已明确配置过共享的机器人可继续共享，也可为确认曾共享的老机器人手动选择这个模式。

私聊对话仍按发送者分开。升级后旧私聊记录保留在原会话，新的入站消息使用带应用、实例和记忆权限的会话，切换到个人范围时不会载入工作区会话。

要核对已有绑定，可临时在 `config.json` 设置 `"debug": true` 并重启 CowAgent，然后用自己的飞书账号给同一个机器人发一条便于识别的私聊消息。在 `run.log` 中找到这条消息对应的接收事件，查看 `event.sender.sender_id.open_id` 是否与该实例 Owner 名单中的某个 ID 完全一致。核对后恢复日志级别。

在 Web 控制台或桌面端的飞书通道「手动填写」页，可以为每个机器人保存「接收私聊消息」开关。开关默认开启。关闭后 CowAgent 忽略发给该机器人的私聊消息，群聊照常处理。

- **群聊**在同一飞书应用和 Agent 工作区内按群共享记忆，即使关闭共享会话也是如此。每位发言人在当前群中有独立的 Markdown 档案。群聊跳过工作区根目录的 `USER.md`、`MEMORY.md` 和 `BOOTSTRAP.md`。
- **个人范围**内的记忆搜索、读取和自动摘要使用该发言人的私聊记忆。使用工作区范围的私聊会读写共用记忆。
- **更新档案**时，使用工作区范围的私聊会更新根目录的 `USER.md`。群聊和使用个人范围的私聊通过 `member_profile` 更新发言人自己的档案。没有发言人标记的旧消息仍保留为身份未知。如需从空白上下文开始，请新建会话。

<Note>
  文件和记忆工具会应用对应的访问范围。个人范围和群聊使用受限工具集。
</Note>
