---
title: write - 文件写入
description: 创建或覆盖写入文件
---

写入内容到文件。文件不存在则自动创建，已存在则整体覆盖。自动创建父目录。

修改已有文件时优先使用 `edit`，它只传改动的部分；`write` 用于新建文件或整体重写。

## 依赖

无额外依赖，默认可用。

## 参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `path` | string | 是 | 文件路径 |
| `content` | string | 是 | 要写入的内容 |

## 安全检查

写入前会做几项检查，异常时在结果中给出提示：

- **文件被外部改动**：若文件在 Agent 读取之后被其他程序修改过，会附带提醒，避免覆盖他人改动。
- **语法检查**：内容若是 JSON / YAML / TOML 且解析失败，会**拒绝写入**并保持文件原样——这类文件半截即损坏，也能顺带拦下模型输出被截断的情况。源码文件（如 `.py`）只在本次写入引入了新语法错误时给出告警，不阻止写入。
- **凭证保护**：存放 API Key 的 `~/.cow/.env` 不允许通过本工具写入，请使用 `env_config` 工具。
- **MCP 配置保护**：CowAgent 管理的 `mcp.json`（`~/cow/mcp.json`、`~/.cow/mcp.json` 以及各 Agent 副本）不允许通过本工具写入，请自行编辑该文件。
- **工作区限制（可选）**：在 `config.json` 中设置 `tools.write.restrict_to_workspace` 为 `true`，可拒绝写入 Agent 工作区以外的路径。默认关闭。

## 使用场景

- 创建新的代码文件或脚本
- 生成配置文件
- 保存处理结果
