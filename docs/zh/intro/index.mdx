**CowAgent** 是开源的 Personal Agent，属于你自己的超级 AI 助理：能主动规划任务，调用工具、技能与 MCP，通过长期记忆、知识库和自进化能力越用越懂你。

CowAgent 支持多模型、多通道、多智能体，能处理文本、语音、图片、文件等多模态消息，可接入微信、飞书、钉钉、企业微信、QQ、网页等渠道，7×24 小时运行于个人电脑或服务器中。它既是开箱即用的 AI 助理，也是开放可扩展的 Agent Harness。

## 核心能力

## 快速体验

在终端执行以下命令，即可一键安装、配置、启动 CowAgent：

<Tabs>
  <Tab title="Linux / macOS">
    ```bash
    bash <(curl -fsSL https://cdn.link-ai.tech/code/cow/run.sh)
    ```
  </Tab>
  <Tab title="Windows (PowerShell)">
    ```powershell
    irm https://cdn.link-ai.tech/code/cow/run.ps1 | iex
    ```
  </Tab>
  <Tab title="Docker">
    ```bash
    curl -O https://cdn.link-ai.tech/code/cow/docker-compose.yml
    docker compose up -d
    ```
  </Tab>
</Tabs>

运行后默认会启动 Web 控制台，通过访问 `http://localhost:9899` 可以在网页端进行对话、配置、应用通道接入等操作。

也可以使用桌面客户端（macOS / Windows），内置 Agent 运行环境，[下载安装](https://cowagent.cn/zh/download/)后开箱即用。

不想自己部署和准备模型 Key，还可以 [在线使用](https://cloud.cowagent.cn)：在浏览器中创建专属实例，内置模型服务，7×24 小时在线。详见 [云端托管](/zh/guide/cloud)。
