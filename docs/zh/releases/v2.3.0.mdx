## 📱 移动端 App

CowAgent 推出移动端 App，支持 iOS、Android 与鸿蒙，适配手机与平板。App 提供两种使用方式：直接在手机上运行 Agent，或连接电脑、服务器上的 CowAgent。

> 目前为公开测试阶段，iOS 需通过 TestFlight 安装，Android 可直接下载 APK 文件，鸿蒙通过应用市场的测试链接安装，正式版即将上架各应用商店。前往 [下载页](https://cowagent.cn/zh/download/#mobile) 扫码即可安装，欢迎体验并通过 [GitHub Issues](https://github.com/zhayujie/CowAgent/issues) 反馈问题和建议。

  <img src="https://cdn.link-ai.tech/doc/mobile-app-zh.png" alt="移动端 App" width="800" />

- **在手机上运行**：App 内置完整的 Agent 内核，无需电脑或服务器，配置模型后即可使用对话、技能、记忆、知识库和定时任务，数据保存在手机本地。
- **连接其他设备**：扫描配对二维码即可连接电脑或服务器上的 CowAgent，在手机上继续对话、查看产物、管理任务等；可保存多个设备，随时切换。
- **手机能力**：在手机上运行时，Agent 可以打开应用和链接（导航、拨号、短信、邮件）、获取位置、读写日历、查询通讯录、选取照片、分享文件和查看设备状态。每次操作前都会询问，也可设为始终允许。
- **通知与提醒**：App 在后台时，回复完成和定时任务结果通过系统通知送达，点击直接进入对应会话；手机上创建的定时任务交由系统按时执行。
- **对话体验**：支持流式回复、附件与语音输入，多个会话可同时回复；回复可随时停止，中断的回复可以继续生成，也可重新生成回复或编辑已发送的问题。
- **文件**：其他应用中的文件和文字可直接分享到对话，对话中的文件也可分享到其他应用。
- **完整管理**：Agent、技能、MCP、知识库、记忆、定时任务、通道、访客页面、模型与能力等配置与 Web 控制台保持一致，均可在手机上管理。
- **其他**：支持多语言界面；设备凭证保存在 iOS 钥匙串和 Android Keystore 中。

Thanks @zkjqd、@a1094174619

## 🔗 设备管理

Web 控制台、桌面客户端与移动端新增设备管理，各端可以互相连接，在一处操作多台设备上的 CowAgent：

- **配对连接**：在「设备管理」中点击「让其他设备连接我」，生成二维码与配对码（5 分钟内有效，仅可使用一次）；手机扫码连接，电脑输入地址和配对码连接。没有界面的服务器上可运行 `cow pair`，在终端中显示配对码和二维码。
- **设备切换**：Web 控制台、移动端、桌面客户端可连接其他电脑或服务器上的 CowAgent 实例，并在设备之间切换操作，例如在手机或笔记本上管理服务器上的 Agent。
- **云端实例**：[云端托管](https://docs.cowagent.ai/zh/guide/cloud) 的实例同样支持通过配对连接，手机扫码后不受网络环境限制，随时随地可用。
- **设备列表**：「连接我的设备」列出所有已连接的设备，显示连接方式（配对连接或密码登录）和最近活跃时间，可修改名称或移除，移除后立即断开。
- **独立凭证**：每台设备使用独立的登录凭证，Agent 无法读取。

## 🤖 模型能力

- **CowAgent 模型服务**：一个 API Key 即可使用 Claude、GPT、Gemini、DeepSeek、Qwen 等主流模型，同时覆盖图像理解、图像生成、语音、向量和联网搜索。相关文档：[CowAgent 模型服务](https://docs.cowagent.ai/zh/models/cowagent)
- **Codex 订阅**：使用 ChatGPT 授权登录后，CowAgent 会通过你的账号订阅调用 GPT 模型，无需 API Key，Web 控制台与桌面客户端均可登录（Thanks @shuaiplus #4019、@6vision #4052）。
- **新模型**：新增 `gemini-4-neon`（Gemini 默认模型）、`gemini-4-carbon`、`gemini-4-hydrogen`、`gpt-6.2-sol`（OpenAI 默认模型）、`gpt-6.2-astra`、`claude-fable-5-2`，图像生成新增 `gpt-image-2.6-flare`、`gpt-image-2.6-sunburst`、`gemini-nano-banana-2.1`。
- **语音**：新增 DeepSeek 语音识别与语音合成。
- **思考强度**：Web 控制台的模型设置中可配置思考强度（Thanks @shuaiplus #4040）。
- **图像理解**：LinkAI 图像理解默认使用 `deepseek-flash`，主模型具备视觉能力时直接传图（Thanks @6vision #4048）。
- **稳定性**：Claude 多轮工具调用时保留思考内容；仅返回心跳的流式连接会按时结束，不再长时间挂起（Thanks @c020627 #3892, #3909, #3912、@eric7h #3930）；OpenAI Responses 接口兼容带 `dependentRequired` 的 MCP 工具参数，并保留流式错误信息（Thanks @linzch3 #4005, #4006、@Alion548 #4002）。
- **其他**：Gemini 返回准确的结束原因，限制远程图片下载大小（Thanks @c020627 #3903, #4009）；补充 Kimi K3.1 上下文长度（Thanks @JohnQsk #3876）；ModelScope 工具调用携带系统提示词（Thanks @pcbeingused333 #3974）；对话 API 不同会话的请求互不阻塞（Thanks @thejesh23 #4034）；LinkAI 对话历史按上下文预算裁剪（Thanks @c020627 #3922）；修复讯飞语音的若干问题，语音识别多次修正后不再残留旧文字，长语音不再丢失结尾内容（Thanks @c020627 #3899、@MrGendo #3968、@nurlanmnn #4059、@pcbeingused333 #4066）。

## 📦 升级方式

- **源码部署**：执行 `cow update` 一键升级，或在 Web 控制台侧边栏版本菜单中一键更新，也可手动拉取代码后重启。详见 [更新升级文档](https://docs.cowagent.ai/zh/guide/upgrade)。
- **桌面客户端**：可在客户端内自动检查并一键更新，或前往 [下载页](https://cowagent.cn/zh/download/) 获取最新版本。
- **移动端**：公开测试中，iOS 通过 TestFlight 安装，Android 下载安装包，鸿蒙通过华为应用市场邀请测试安装，详见 [下载页](https://cowagent.cn/zh/download/#mobile) 与 [移动端文档](https://docs.cowagent.ai/zh/guide/mobile#下载安装)。

升级前请注意：

- 移动端与其他设备连接时，对方的 CowAgent 需升级至 2.3.0 及以上，且监听地址可被访问（不能只监听本机），建议设置访问密码。
- 如有其他网站的页面需要调用控制台接口，请将该网站加入 `web_allowed_origins`。
- 通过 Nginx 等反向代理访问时，请转发 `Host` 与 `X-Real-IP` 请求头，以便正确识别访问地址和客户端 IP。
