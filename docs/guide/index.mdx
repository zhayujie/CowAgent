title: Choose How to Use
description: "CowAgent can be used through a source install, the desktop client, the mobile app, or CowAgent Cloud. Choose by where it runs and how you use it, or combine them."
---

CowAgent can be used in the following ways. Pick one to get started:

<CardGroup cols={2}>
  <Card title="One-click Source Install" icon="terminal" href="/guide/quick-start">
    Install on Linux, macOS or Windows with one command. Suited to developers and servers, with the most room for customization.
  </Card>
  <Card title="Desktop Client" icon="desktop" href="/guide/desktop">
    macOS / Windows client with the runtime built in. No Python or other dependencies needed; download and run.
  </Card>
  <Card title="Mobile App" icon="mobile-screen-button" href="/guide/mobile">
    iOS / Android / HarmonyOS app (public beta). Run the Agent on your phone, or scan a code to connect to CowAgent on a computer or server.
  </Card>
  <Card title="CowAgent Cloud" icon="cloud" href="/guide/cloud">
    No server or API key needed. A dedicated cloud instance with built-in models, online 24/7.
  </Card>
</CardGroup>

## Which One to Choose

| | Source install | Desktop client | Mobile app | CowAgent Cloud |
| --- | --- | --- | --- | --- |
| Runs on | Your computer or server | Your computer | Your phone, or another connected device | A dedicated cloud instance |
| Models | Configure your own | Configure your own | Configure your own | Built in, or configure your own |
| Availability | Depends on the machine | While your computer is on | Depends on where it runs | 24/7 |
| Best for | Customization, server deployment | Personal local use | Use anywhere | No maintenance, always online |

You can combine them. For example, run the desktop client or a source install on your computer, then connect with the mobile app to use that Agent while you are away. For connecting and switching between devices, see [Device Management](/guide/devices).

To deploy with Docker or by hand, see [Manual Install](/guide/manual-install).
