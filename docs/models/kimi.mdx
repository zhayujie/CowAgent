Kimi is provided by Moonshot and supports both text chat and image understanding. The `kimi-k3.1-pro`, `kimi-k3` and `kimi-k2.x` series natively support vision.

<Tip>
  All capabilities below can be configured in one place via the "Model Management" page in the Web Console, with no need to manually edit the configuration file.
</Tip>

## Text Chat

```json
{
  "model": "kimi-k3.1-pro",
  "moonshot_api_key": "YOUR_API_KEY"
}
```

| Parameter | Description |
| --- | --- |
| `model` | Can be `kimi-k3.1-pro`, `kimi-k3.1-pro-highspeed`, `kimi-k3`, `kimi-k2.7-code`, `kimi-k2.7-code-highspeed`, `kimi-k2.6`, `kimi-k2.5`, `kimi-k2`, `moonshot-v1-8k`, `moonshot-v1-32k`, `moonshot-v1-128k` |
| `moonshot_api_key` | Create one in the [Moonshot Console](https://platform.kimi.com?aff=cowagent) |
| `moonshot_base_url` | Optional, defaults to `https://api.moonshot.cn/v1` |

`kimi-k3.1-pro` is the default recommendation with a 1M-token context window; `kimi-k3.1-pro-highspeed` offers the same intelligence at roughly 2-3x the output speed. The K3 / K3.1 series always think; tune the depth with `reasoning_effort`: `low` / `high` / `max` (default `max`).

## Image Understanding

Once `moonshot_api_key` is configured, the Agent's Vision tool automatically uses `kimi-k2.6` to recognize images, with no extra setup required.

To manually specify a Vision model:

```json
{
  "tools": {
    "vision": {
      "model": "kimi-k2.6"
    }
  }
}
```
