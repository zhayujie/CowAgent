> Coding Plan is a monthly subscription package offered by various providers, ideal for high-frequency Agent usage. CowAgent supports all Coding Plan providers via OpenAI-compatible mode.

<Note>
  Coding Plan API Base and API Key are usually separate from the standard pay-as-you-go ones. Please obtain them from each provider's platform.
</Note>

## General Configuration

All providers can be accessed via the OpenAI-compatible protocol, and can be quickly configured through the web console. Set the model provider to **OpenAI**, select a custom model and enter the model code, then fill in the corresponding provider's API Base and API Key:

<img src="https://cdn.link-ai.tech/doc/20260318113134.png" width="800"/>

You can also configure directly in `config.json`:

```json
{
  "bot_type": "openai",
  "model": "MODEL_NAME",
  "open_ai_api_base": "PROVIDER_CODING_PLAN_API_BASE",
  "open_ai_api_key": "YOUR_API_KEY"
}
```

| Parameter | Description |
| --- | --- |
| `bot_type` | Must be `openai` (OpenAI-compatible mode) |
| `model` | Model name supported by the provider |
| `open_ai_api_base` | Provider's Coding Plan API Base URL |
| `open_ai_api_key` | Provider's Coding Plan API Key |

## MiniMax M Plan (China)

The current China M Plan subscriptions (Go, Explore and Build) support `MiniMax-M3.1-Flash`. Obtain an M Plan subscription key from the [M Plan console](https://platform.minimax.cn/console/plan), then configure CowAgent's OpenAI-compatible mode:

```json
{
  "bot_type": "openai",
  "model": "MiniMax-M3.1-Flash",
  "open_ai_api_base": "https://api.minimax.cn/v1",
  "open_ai_api_key": "YOUR_M_PLAN_API_KEY"
}
```

| Parameter | Description |
| --- | --- |
| `model` | `MiniMax-M3.1-Flash` |
| `open_ai_api_base` | `https://api.minimax.cn/v1` |
| `open_ai_api_key` | Subscription key from the China M Plan console |

The official M Plan guide also documents the Anthropic-compatible base `https://api.minimax.cn/anthropic` with the same model ID; the configuration above uses OpenAI-compatible mode.

### Legacy Coding Plan

This is a separate onboarding path for the current China M Plan. Earlier Coding Plan examples used `https://api.minimaxi.com/v1`; do not assume an existing Coding Plan key or saved configuration can be migrated to M Plan. Check your account's product and model entitlements before changing it. The current M Plan documentation cited here does not establish `MiniMax-M3` subscription entitlement or gateway support. Existing saved/custom configurations are not changed by this guide.

Reference: [M Plan overview](https://platform.minimaxi.com/docs/token-plan/intro.md), [M Plan tool configuration](https://platform.minimaxi.com/docs/m-plan/other-tools.md)
