デバイス管理は、複数のデバイス上の CowAgent を接続するための機能です。たとえば、スマートフォンで QR コードを読み取って PC 上の Agent を使ったり、ノート PC から自宅の PC やサーバーに切り替えて操作したり、接続済みのデバイスをいつでも確認・削除したりできます。

Web コンソールとデスクトップクライアントでは「設定 → デバイス管理」、モバイルアプリでは「設定 → デバイス管理」から開けます。

ページは 3 つの部分に分かれています：

- **このデバイス**：現在の CowAgent の名前とバージョン。名前の横の編集ボタンで名前を変更でき、他のデバイスにもこの名前が表示されます。
- **接続先のデバイス**：このデバイスから接続した他の CowAgent。切り替えて操作できます。
- **接続元のデバイス**：現在の CowAgent に接続しているスマートフォン、PC、ブラウザ。いつでも削除できます。

## 他のデバイスから接続

「接続元のデバイス」で「他のデバイスから接続」をクリックすると、ペアリング用 QR コード、ペアリングコード、接続アドレスが表示されます：

- **スマートフォン**：CowAgent アプリで QR コードを読み取ります。
- **PC**：相手側の「設定 → デバイス管理」で「他のデバイスに接続」をクリックし、アドレスとペアリングコードを入力します。

ペアリングコードの有効期限は 5 分で、1 回のみ使用できます。相手の接続が完了すると、ページに自動で通知されます。

<Frame>
  <img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/devices-pair.png" alt="ペアリングコードの生成" width="800" />

<Note>
  他のデバイスから現在の CowAgent にアクセスできる必要があります。サービスがこのマシンのみ（`127.0.0.1`）でリスンしている場合はページに案内が表示されるので、「設定 → 連携設定 → アクセス URL」でリスンアドレスを変更してください。ドメインでアクセスする場合は表示用アドレスを設定すると、ペアリング用 QR コードにはそのアドレスが優先して使われます。
</Note>

### サーバーでペアリングコードを生成

画面のないサーバーでは、次のコマンドを実行します：

```bash
cow pair
```

ターミナルにペアリングコード、接続アドレス、QR コードが表示され、デバイスの接続を待ちます。サーバーのグローバルアドレスが自動で認識されない場合は、`--url` で指定できます：

```bash
cow pair --url http://203.0.113.5:9899
```

`--no-wait` を付けると、接続を待たずにペアリングコードだけを出力します。

## 他のデバイスに接続

Web コンソールまたはデスクトップクライアントの「接続先のデバイス」で「他のデバイスに接続」をクリックし、相手のアドレスとペアリングコードを入力します。ペアリング用リンクをそのまま貼り付けることもできます。スマートフォンからの接続方法は [モバイルアプリ](/ja/guide/mobile#他のデバイスに接続) を参照してください。

接続後は次のように操作します：

- 「接続先のデバイス」で「切り替え」をクリックするか、サイドバー上部のデバイス切り替えを使うと、相手の CowAgent を操作できます。会話、設定、ファイルはすべて相手のデバイスのものです。
- サイドバーには操作中のデバイスが常に表示され、「このデバイスに戻る」をクリックすると戻ります。
- 相手の電源が切れている、ネットワークから切断されている、アドレスが変わった場合は、一覧にアクセスできないと表示されます。相手があなたを削除した場合は、再度ペアリングが必要です。

<Note>
  ブラウザでデバイスを切り替えるには、ページを `localhost` または HTTPS で開いている必要があります。HTTPS のページからは HTTP のアドレスに接続できないため、HTTPS のアドレスを使うか、デスクトップクライアントから接続してください。
</Note>

## 接続元のデバイス

現在の CowAgent に接続しているすべてのデバイスが一覧表示され、デバイス名、接続方法（ペアリング接続またはパスワードでのログイン）、バージョン、IP、最終アクティブ時刻を確認できます。

- **名前の変更**：複数のデバイスを区別しやすくします。
- **デバイスの削除**：削除したデバイスは直ちに切断され、再度ペアリングまたはログインが必要になります。

## セキュリティ

- 接続したデバイスにはすべての操作権限があり、コマンドの実行やファイルの読み書きができます。信頼できるデバイスとのみペアリングしてください。
- デバイスごとに個別のログイン認証情報を使うため、1 台を削除しても他のデバイスには影響しません。アクセスパスワードを変更した場合、再ログインが必要なのはパスワードでログインしたデバイスだけです。
- デバイスのデータは `~/.cow/device` ディレクトリに保存され、Agent からは読み取れません。
- アクセスパスワードを設定していない場合、同じネットワーク内の誰でもコンソールにアクセスできます。ページに警告が表示されるので、他のデバイスに公開する前にパスワードを設定してください。
- CowAgent の前段にログインゲートウェイ（リバースプロキシでの認証など）がある場合は、ペアリングコードで接続できません。
- Nginx などのリバースプロキシ経由でアクセスする場合は、アクセスアドレスとデバイスの IP を正しく識別できるよう、`Host` と `X-Real-IP` ヘッダーを転送してください。詳しくは [Web コンソール](/ja/channels/web#https-とドメインでのアクセス) を参照してください。
