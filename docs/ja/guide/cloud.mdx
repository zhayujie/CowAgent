サーバーやモデルのキーを自分で用意したくない場合は、CowAgent をクラウド上で直接実行できます。各クラウドインスタンスは完全な CowAgent で、ソースインストールやデスクトップクライアントと同じオープンソースのコードで動作するため、Web コンソール、スキル、メモリ、チャネルの使い方はまったく同じです。

## 特長

- **専用インスタンス**：各インスタンスは分離された独立の環境で動作し、専用のワークスペース、メモリ、スキルを持ちます。
- **モデルを内蔵**：[CowAgent モデルサービス](/ja/models/cowagent) に接続済みのため、会話、画像、音声、ベクトル、Web 検索を API キーなしですぐに使えます。「モデル管理」から他のプロバイダーに切り替えることもできます。
- **常時稼働**：24 時間 365 日稼働するため、PC の電源を切ってもスケジュールタスクやチャネルのメッセージは通常どおり処理されます。

## はじめに

1. [cloud.cowagent.ai](https://cloud.cowagent.ai/?utm_source=docs) にログインします。中国本土のユーザーは、電話番号でのログインに対応した [cloud.cowagent.cn](https://cloud.cowagent.cn/?utm_source=docs) を利用できます。2 つのサイトのアカウントは共通ではありません。
2. プランを選択し、「インスタンス」ページでインスタンスを作成します。
3. 「開く」をクリックしてインスタンスの Web コンソールに入ると、会話を始めたり、Telegram や Slack などのチャネルを接続したり、スキルをインストールしたりできます。

## スマートフォンとデスクトップクライアントからの接続

インスタンスカード右上の「···」メニューから「デバイス」をクリックし、[CowAgent アプリ](/ja/guide/mobile) でペアリング用 QR コードを読み取ると、スマートフォンからいつでもクラウドインスタンスを使えます。デスクトップクライアントやローカルの Web コンソールからもペアリングでクラウドインスタンスに接続し、このマシンと切り替えて操作できます。詳しくは [デバイス管理](/ja/guide/devices) を参照してください。

## 選び方

| | ソースインストール | デスクトップクライアント | CowAgent Cloud |
| --- | --- | --- | --- |
| 実行場所 | 自分の PC またはサーバー | この PC | クラウド上の専用インスタンス |
| モデル設定 | 自分で設定 | 自分で設定 | 内蔵、自分で設定も可能 |
| 稼働時間 | マシンによる | PC の起動中 | 24 時間 365 日 |
| 向いている用途 | カスタマイズ、完全な管理 | 個人のローカル利用 | 運用不要、常時稼働 |

これらの方法は組み合わせて使えます。たとえば普段の作業は PC のデスクトップクライアントで行い、チャットチャネルに接続した常時稼働のアシスタントをクラウドで動かす、といった使い方ができます。
