CowAgent アプリは現在**公開ベータ版**で、各アプリストアへの掲載も順次進めています。iOS、Android、HarmonyOS に対応し、スマートフォンとタブレットで利用できます。使い方は 2 つあります：

- **このスマートフォンで実行**：Agent はこのスマートフォン上で動作し、データもスマートフォン内に保存されます。許可すれば、カレンダー、連絡先、写真、位置情報などスマートフォンの機能を利用できます。
- **PC に接続**：QR コードを読み取って PC、サーバー、クラウドインスタンス上の CowAgent に接続し、コマンドの実行、ファイルの読み書き、ブラウザの操作を含むすべての機能をスマートフォンから使えます。

2 つの使い方はサイドバーからいつでも切り替えられます。

**ダウンロード**：[cowagent.ai/download](https://cowagent.ai/download/#mobile)

## ダウンロードとインストール

[ダウンロードページ](https://cowagent.ai/download/#mobile) からのインストールをおすすめします。PC で開いてスマートフォンで QR コードを読み取るか、スマートフォンで直接開くと、お使いのシステムに合ったインストール方法に自動で移動します。次の手順で手動インストールすることもできます：

<Tabs>
  <Tab title="iOS">
    iOS 15.1 以降の iPhone と iPad に対応しています。

    1. App Store から Apple 公式の「TestFlight」をインストールします。
    2. スマートフォンで [公開ベータのリンク](https://testflight.apple.com/join/JG9VxmXj) を開き、「同意する」、続いて「インストール」をタップします。
    3. 新しいバージョンが公開されると、TestFlight から更新の通知が届きます。
  </Tab>
  <Tab title="Android">
    Android 7.0 以降に対応しています。

    1. スマートフォンのブラウザで [ダウンロードリンク](https://cowagent.ai/download/android/latest) を開き、インストールパッケージ（APK）をダウンロードします。
    2. ダウンロードしたファイルを開いてインストールします。「提供元不明のアプリ」のインストールがブロックされた場合は、表示に従ってブラウザからのインストールを許可してください。
    3. 新しいバージョンがあるとアプリに更新の案内が表示されます。「設定 → アップデート」から手動で確認することもできます。
  </Tab>
  <Tab title="HarmonyOS">
    HarmonyOS 5.0 以降のスマートフォンとタブレットに対応しています。

    1. スマートフォンで [招待テストのリンク](https://appgallery.huawei.com/link/invite-test-wap?taskId=534ec7245d8f271ca2d1ef0bc73f38b5&invitationCode=5MsQJ5iPGD6) を開き、Huawei AppGallery でテストに参加します。
    2. 「インストール」をタップし、インストールが完了したらアプリを開きます。
    3. 新しいバージョンが公開されたら、AppGallery からアップデートします。
  </Tab>
</Tabs>

問題が発生した場合は、[GitHub Issues](https://github.com/zhayujie/CowAgent/issues) またはメール support@cowagent.ai からお知らせください。スマートフォンの機種、OS のバージョン、アプリのバージョン（「設定 → アップデート」）、使い方（スマートフォンで実行か PC に接続か）を添えていただけると助かります。

## このスマートフォンで実行

1. 初めてアプリを開いたら「このスマートフォンで実行」を選び、「次へ」をタップします。
2. チャット画面の「モデルを設定」カードで「設定する」をタップし、モデルプロバイダー（DeepSeek、Qwen、CowAgent など）の API キーを入力して保存します。
3. チャット画面に戻ると会話を始められます。

この使い方では、会話、メモリ、ナレッジベースなどのデータはすべてスマートフォン内に保存され、会話の内容は設定したモデルプロバイダーにのみ送信されます。スマートフォンにはコマンドラインとブラウザがないため、Agent はコマンドの実行とブラウザの操作を行わず、計算やファイル処理には内蔵の Python を使います。すべての機能が必要な場合は PC に接続してください。

### スマートフォンの機能

スマートフォンで実行している場合、Agent は次の機能を利用できます。操作の前には毎回確認し、「常に許可し、今後確認しない」に設定することもできます：

| 機能 | 説明 |
| --- | --- |
| アプリやリンクを開く | Web ページや他のアプリを開き、ナビゲーション、電話、SMS、メールを開始します。操作の完了はそのアプリで行います |
| 位置情報 | 現在地を取得し、周辺の検索、天気の確認、ナビゲーションに使います |
| カレンダー | 予定の確認、予定とリマインダーの追加 |
| 連絡先 | 名前で連絡先の電話番号とメールアドレスを検索します |
| 写真の選択 | 写真ライブラリから選んだ写真を Agent に渡します。共有されるのは選択した写真だけです |
| ファイルの共有 | システムの共有シートを開き、ファイルを他のアプリに送ります |
| デバイスの状態 | バッテリー、ネットワーク、ストレージ、省電力モードなどの状態を確認します |
| Python の実行 | 計算、データ処理、ファイル変換（CSV / Excel / PDF など）のほか、スキル内のスクリプトも実行できます |

ある機能を初めて使うときは、システムが対応する権限を求めます。各権限の状態は「設定 → アプリの権限」で確認できます。常に許可に設定した操作は、会話内のそのステップの下にある「毎回確認する」をタップすると、確認を再開できます。

### 通知とスケジュールタスク

アプリがバックグラウンドにあるときは、返信の完了とスケジュールタスクの結果がシステム通知で届き、通知をタップすると該当する会話を開きます。スマートフォンで作成したスケジュールタスクとリマインダーはシステムが予定どおりに実行するため、アプリを前面に表示しておく必要はありません。

## 他のデバイスに接続

接続すると、スマートフォンで使うのは接続先のデバイス上の Agent になり、会話とデータは接続先のデバイスに保存されます。自分の PC やサーバーにデプロイした CowAgent にも、クラウドインスタンスにも接続できます。

### PC またはサーバーに接続

**前提条件**：

- 接続先の CowAgent のバージョンが 2.3.0 以降であること。
- スマートフォンから接続先にアクセスできること：通常は同じ Wi-Fi に接続しているか、接続先にインターネットからアクセスできるアドレスがある必要があります。サーバーのポートをインターネットに公開する場合は、アクセスパスワードとセキュリティグループを設定してください。
- 接続先がこのマシンのみ（`127.0.0.1`）でリスンしていないこと。「設定 → 連携設定 → アクセス URL」で変更できます。

**接続手順**：

1. PC の CowAgent で「設定 → デバイス管理」を開き、「他のデバイスから接続」をクリックしてペアリング用 QR コードを生成します。サーバーでは `cow pair` を実行してペアリングコードを取得することもできます。
2. アプリで「PC に接続」を選ぶ（初回起動時）か、サイドバーのデバイス切り替えから「QR コードで接続」を選びます。
3. QR コードを読み取って確認すると、PC 上の Agent を使えるようになります。

<Frame>
  <img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/devices-pair.png" alt="ペアリング用 QR コードの生成" width="800" />

QR コードを読み取れない場合は「アドレスを入力」を選び、接続先のアドレスとペアリングコードを入力することもできます。ペアリングコードの有効期限は 5 分で、1 回のみ使用できます。接続後は、サイドバーから「このデバイス」と接続済みのデバイスをいつでも切り替えられます。

詳しくは [デバイス管理](/ja/guide/devices) を参照してください。

### クラウドインスタンスに接続

PC やサーバーがない場合は、[CowAgent Cloud](/ja/guide/cloud) のインスタンスに接続できます：クラウドコンソールでインスタンスカード右上の「···」メニューから「デバイス」をクリックし、表示されたペアリング用 QR コードをアプリで読み取ります。クラウドインスタンスにはインターネットからアクセスできるアドレスがあるため、ネットワーク環境を問わずいつでもどこでも利用できます。

## 主な機能

- **会話**：ストリーミング返信、音声入力、画像やファイルの添付に対応し、2 つのセッションで同時に返信できます。返信はいつでも停止でき、中断した返信の続きを生成したり、返信を再生成したり、送信済みの質問を編集したりできます。
- **ファイル**：他のアプリのファイルやテキストをアプリに直接共有でき、会話内のファイルを他のアプリに共有することもできます。ファイルはアプリ内でダウンロードされ、中断したダウンロードの再開に対応しています。
- **管理**：Agent、スキル、MCP、ナレッジベース、メモリ、スケジュールタスク、チャネル、ゲストページ、モデル設定などは Web コンソールと共通です。
- **画面**：中国語と英語、ライトモードとダークモードに対応し、iPad やタブレットの縦横表示と画面分割にも対応しています。

## アップデート

- **iOS**：新しいバージョンがあると TestFlight から通知が届くので、TestFlight で「アップデート」をタップします。
- **Android**：新しいバージョンがあるとアプリに更新の案内が表示されます。ダウンロード後にインストールパッケージを検証してから、システムにインストールを引き渡します。「設定 → アップデート」から手動で確認することもできます。
- **HarmonyOS**：新しいバージョンが公開されたら、Huawei AppGallery からアップデートします。

## よくある質問

**QR コードを読み取った後に接続できない**

スマートフォンと PC が同じネットワークにあること、PC 上で CowAgent が起動していること、このマシンのみでリスンしていないことを確認してください。応答がない場合は、PC のファイアウォールにブロックされている可能性があります。

**バージョンが古いと表示される**

アプリから接続するには、接続先の CowAgent が 2.3.0 以降である必要があります。先に [アップグレード](/ja/guide/upgrade) してください。

**先にログインが必要と表示される**

接続先の前段にログインゲートウェイ（リバースプロキシでの認証など）があるため、アプリからペアリングコードで直接接続できません。ゲートウェイを無効にするか、CowAgent へのアクセスを個別に許可してください。
