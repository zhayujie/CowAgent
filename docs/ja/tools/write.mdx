---
title: write - ファイル書き込み
description: ファイルの作成または上書き
---

ファイルにコンテンツを書き込みます。ファイルが存在しない場合は新規作成し、存在する場合はファイル全体を上書きします。親ディレクトリは自動的に作成されます。

既存ファイルを変更する場合は `edit` を優先してください。変更する部分だけを送信します。`write` は新規作成と全体の書き直しに使います。

## 依存関係

追加の依存関係は不要で、デフォルトで利用可能です。

## パラメータ

| パラメータ | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `path` | string | はい | ファイルパス |
| `content` | string | はい | 書き込む内容 |

## 安全チェック

書き込み前にいくつかのチェックが実行され、問題があれば結果に含めて通知します：

- **外部での変更**：Agent が読み取った後にそのファイルが他のプログラムによって変更されていた場合、警告が付きます。他者の変更を上書きしないためです。
- **構文チェック**：内容が JSON / YAML / TOML でパースに失敗する場合、**書き込みを拒否**しファイルはそのまま保持されます。これらの形式は途中まででは壊れているためで、モデルの出力が途中で切れた場合の検出も兼ねます。ソースコード（`.py` など）は、今回の書き込みが新たな構文エラーを生じさせた場合にのみ警告し、書き込み自体は妨げません。
- **認証情報の保護**：API キーを保管する `~/.cow/.env` は本ツールでは書き込めません。`env_config` ツールをご利用ください。
- **MCP 設定の保護**：CowAgent が管理する `mcp.json`（`~/cow/mcp.json`、`~/.cow/mcp.json`、および Agent ごとのコピー）は本ツールでは書き込めません。そのファイルは自分で編集してください。
- **ワークスペース制限（任意）**：`config.json` で `tools.write.restrict_to_workspace` を `true` にすると、Agent ワークスペース外への書き込みを拒否します。既定はオフです。

## ユースケース

- 新しいコードファイルやスクリプトの作成
- 設定ファイルの生成
- 処理結果の保存
