現在の作業ディレクトリでターミナルコマンドを実行し、stdoutとstderrを返します。ツール名は `bash` のままですが、構文はサーバーのOSと選択したコマンドインタープリターによって異なります。`env_config` で設定されたAPIキーは自動的に環境変数に注入されます。

## Windows のコマンドインタープリター

Windows のデフォルトは CMD です。**能力 → 内蔵ツール → bash → コマンド実行設定** から **PowerShell 7** を選択できます。検出は CowAgent の実行サーバー上で行われ、`pwsh` のインストールが必要です。Windows PowerShell 5.1 はサポートされません。PowerShell 7 が利用できない場合は保存できず、実行時に CMD へ自動フォールバックすることもありません。

この設定は現在のインスタンスに属するすべての Agent に適用され、`tools.bash.windows_shell` に保存されます。値はデフォルトの `cmd` または `pwsh` です。以降のモデルリクエストではツール説明と構文が更新され、実行中のバックグラウンドジョブは元のプロセスを継続します。Linux と macOS の動作は変更されません。

PowerShell 7 はプロファイルなしの非対話モードで実行され、UTF-8 出力を使用します。環境変数には `$env:NAME`、出力のリダイレクトには `$null` を使用してください。`$ErrorActionPreference = 'Stop'` が設定されるため、コマンドレットのエラーは実行を停止して非ゼロ終了コードを返します。ネイティブコマンドの終了コードも保持されます。切り替え後に CMD の `%NAME%` や `>nul` などの構文を再利用しないでください。

## 依存関係

追加の依存関係は不要で、デフォルトで利用可能です。

## パラメータ

| パラメータ | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `command` | string | はい | 実行するコマンド |
| `timeout` | integer | いいえ | タイムアウト（秒） |

## ユースケース

- パッケージや依存関係のインストール
- コードやテストの実行
- アプリケーションやサービスのデプロイ（Nginx設定、プロセス管理など）
- システム管理とトラブルシューティング
