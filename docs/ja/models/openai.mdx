OpenAI は最も広範な機能をカバーするベンダーで、テキスト対話、画像理解、画像生成、音声認識（ASR）、音声合成（TTS）、ベクトル（Embedding）の各機能を同時に担えます。1 つの `open_ai_api_key` で Agent はすべての機能を利用できます。

<Tip>
  Web コンソールの「モデル管理」ページから、以下のすべての機能をワンストップで設定でき、設定ファイルを手動で編集する必要はありません。
</Tip>


## テキスト対話

```json
{
  "model": "gpt-6.2-sol",
  "open_ai_api_key": "YOUR_API_KEY",
  "open_ai_api_base": "https://api.openai.com/v1"
}
```

| パラメータ | 説明 |
| --- | --- |
| `model` | OpenAI API の [model パラメータ](https://platform.openai.com/docs/models) と同じです。`gpt-6.2-sol`、`gpt-6.2-astra`、`gpt-6.1-terra`、`gpt-6.1-sol`、`gpt-6-luna`、`gpt-6-sol`、`gpt-6-astra`、`gpt-5.6-luna`、`gpt-5.6-terra`、`gpt-5.6-sol`、`gpt-5.5`、`gpt-5.4`、`gpt-5.4-mini`、`gpt-5.4-nano`、`gpt-5` シリーズ、`gpt-4.1` などをサポート。Agent モードのデフォルトは `gpt-6.2-sol`、`gpt-6.2-astra` は最強のフラッグシップ（最高の知能・高コスト）、`gpt-6.1-terra` は高速・高効率で視覚推論に強い、`gpt-6` シリーズ（`gpt-6.1` / `gpt-6.2` を含む）のツール呼び出しは Responses API 経由。コストパフォーマンスを重視する場合は `gpt-5.4` に変更可能 |
| `open_ai_api_key` | [OpenAI プラットフォーム](https://platform.openai.com/api-keys) で作成 |
| `open_ai_api_base` | 任意。サードパーティのプロキシに接続するために変更可能 |
| `open_ai_api_type` | 任意。API プロトコル、デフォルトは `auto`（`gpt-6` シリーズ（`gpt-6.1` / `gpt-6.2` を含む）のみ Responses API、それ以外は Chat Completions）。接続先が `/chat/completions` を提供しなくなった場合は `responses` に設定すると、すべてのリクエストが `/responses` 経由になります。`chat` は常に `/chat/completions` を使用します。Docker デプロイでは環境変数 `OPEN_AI_API_TYPE` で設定できます |
| `bot_type` | OpenAI 公式モデルを使用する場合は不要。互換プロトコルでベンダーモデルに接続する場合は `openai` に設定 |

## Codex（ChatGPT サブスクリプション）

**Codex** プロバイダーは、ChatGPT のサブスクリプションを通じて GPT モデルを呼び出します。API キーは不要で、個人での利用に適しています。CowAgent は公式の Codex CLI を通じてリクエストを送信し、会話履歴とツール呼び出しは引き続き CowAgent が管理し、既存の権限設定に従います。

### Web コンソールでログイン

1. 「設定 › モデル設定」でプロバイダーに Codex を選び、「ChatGPT でログイン」をクリックします。初回ログイン時は公式の Codex CLI（約 110 MB）が自動でダウンロードされ、進行状況が表示されます。
2. デバイスコードをコピーして OpenAI の認可ページを開き、ChatGPT アカウントでログインしてからデバイスコードを貼り付けて確認します。
3. 認可が完了するとモデル一覧が自動で同期され、会話で Codex のモデルを選択できるようになります。

プロバイダーのダイアログから、モデル一覧の再同期やログアウトができます。リモートのコンソールから Codex のログインを管理するには、先にアクセスパスワードを設定してください。

### ターミナルでログイン

CowAgent のサービスを実行しているユーザーで次を実行します：

```bash
cow codex login
```

Codex CLI がインストールされていない場合はインストールを確認するメッセージが表示されます。`--yes` を付けると自動で確認します。ブラウザのあるマシンでは `cow codex login --browser` も使えます。その他のコマンド：

| コマンド | 説明 |
| --- | --- |
| `cow codex install` | ログインせずに Codex CLI のみをインストール |
| `cow codex status` | ログイン状態を確認 |
| `cow codex models` | 利用可能なモデル一覧を同期 |
| `cow codex logout` | ログアウト |

OpenAI からデバイスコード認可を有効にするよう求められた場合は、ChatGPT のセキュリティ設定で有効にしてください。Codex CLI とそのログイン認証情報は現在の CowAgent インスタンスのデータディレクトリに保存され、自分でインストールした Codex CLI には影響しません。

### 設定ファイルで使用

```json
{
  "bot_type": "codex",
  "model": "MODEL_SLUG"
}
```

`model` には `cow codex models` で表示されるモデルを指定します。LinkAI を有効にしている場合は `use_linkai` を `false` に設定してください。

Codex プロバイダーはテキスト対話とツール呼び出しにのみ使用されます。画像理解、画像生成、音声、ベクトルは別途設定が必要です。利用できるモデルと使用量の上限は、ご利用の ChatGPT プランに従います。

## 画像理解

`gpt-5.5`、`gpt-5.4`、`gpt-4o`、`gpt-4.1` などの OpenAI モデルはネイティブにビジョンをサポートしています。`open_ai_api_key` を設定すると、Agent の Vision ツールは自動的にメインモデルを使用して画像を認識します。メインモデルがビジョンに対応していない場合や明示的に指定したい場合は、設定ファイルで指定できます：

```json
{
  "tools": {
    "vision": {
      "model": "gpt-5.4-mini"
    }
  }
}
```

サポートする Vision モデル：`gpt-5.5`、`gpt-5.4`、`gpt-5.4-mini`、`gpt-5.4-nano`、`gpt-5`、`gpt-4.1`、`gpt-4.1-mini`、`gpt-4o`。

## 画像生成

設定ファイルで画像生成モデルを指定すると、Agent が画像生成スキルを呼び出す際に自動的に OpenAI にルーティングされます：

```json
{
  "skills": {
    "image-generation": {
      "model": "gpt-image-2.5-flare"
    }
  }
}
```

サポートする画像生成モデル：`gpt-image-2.5-flare`（推奨デフォルト）、`gpt-image-2.5-sunburst`、`gpt-image-2.6-flare`、`gpt-image-2.6-sunburst`、`gpt-image-2`、`gpt-image-1`。`gpt-image-2.6` シリーズは `quality` 未指定時に `high` 画質を使用します。

## 音声認識

```json
{
  "voice_to_text": "openai",
  "voice_to_text_model": "gpt-transcribe"
}
```

| パラメータ | 説明 |
| --- | --- |
| `voice_to_text` | `openai` に設定すると OpenAI 音声認識が有効になります |
| `voice_to_text_model` | 任意。デフォルトは `gpt-transcribe`。`gpt-4o-mini-transcribe`、`gpt-4o-transcribe`、`whisper-1` は 2027-02-26 に提供終了 |

認証情報は `open_ai_api_key` を自動的に再利用します。

## 音声合成

```json
{
  "text_to_voice": "openai",
  "text_to_voice_model": "gpt-realtime-2.1-mini",
  "tts_voice_id": "marin"
}
```

| パラメータ | 説明 |
| --- | --- |
| `text_to_voice_model` | 任意。デフォルトは `gpt-realtime-2.1-mini`（Realtime API）。`tts-1`、`tts-1-hd`、`gpt-4o-mini-tts` は 2027-01-06 の提供終了まで利用可能 |
| `tts_voice_id` | 音色：`marin`、`cedar`、`alloy`、`ash`、`ballad`、`coral`、`echo`、`sage`、`shimmer`、`verse`。`fable`、`onyx`、`nova` は `tts-*` モデルのみ |

デフォルトモデルの使用時、API ベースが Realtime API に対応していない場合は `tts-1` に自動で切り替わります。

## ベクトル

```json
{
  "embedding_provider": "openai",
  "embedding_model": "text-embedding-3-small"
}
```

選択可能なモデル：`text-embedding-3-small`、`text-embedding-3-large`、`text-embedding-ada-002`。embedding を変更した後は `/memory rebuild-index` コマンドを実行してインデックスを再構築する必要があります。
