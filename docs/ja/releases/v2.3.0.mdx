## 📱 モバイルアプリ

CowAgent のモバイルアプリを公開しました。iOS、Android、HarmonyOS に対応し、スマートフォンとタブレットで利用できます。アプリには 2 つの使い方があります：スマートフォン上で直接 Agent を実行するか、PC やサーバー上の CowAgent に接続します。

> 現在は公開ベータ版です。iOS は TestFlight からインストールし、Android は APK ファイルを直接ダウンロードできます。HarmonyOS は Huawei AppGallery の招待テストからインストールします。正式版は近日中に各アプリストアで公開予定です。[ダウンロードページ](https://cowagent.ai/download/#mobile) の QR コードを読み取るとインストールできます。ぜひお試しいただき、問題やご意見は [GitHub Issues](https://github.com/zhayujie/CowAgent/issues) からお寄せください。

- **スマートフォンで実行**：アプリに Agent のコア全体を内蔵しているため、PC やサーバーは不要です。モデルを設定すれば、会話、スキル、メモリ、ナレッジベース、スケジュールタスクを利用でき、データはスマートフォン内に保存されます。
- **他のデバイスに接続**：ペアリング用 QR コードを読み取るだけで PC やサーバー上の CowAgent に接続し、スマートフォンから会話の続き、成果物の確認、タスクの管理などを行えます。複数のデバイスを保存し、いつでも切り替えられます。
- **スマートフォンの機能**：スマートフォンで実行している場合、Agent はアプリやリンクを開く（ナビゲーション、電話、SMS、メール）、位置情報の取得、カレンダーの読み書き、連絡先の検索、写真の選択、ファイルの共有、デバイスの状態確認を行えます。操作の前には毎回確認し、常に許可するよう設定することもできます。
- **通知とリマインダー**：アプリがバックグラウンドにあるときは、返信の完了とスケジュールタスクの結果をシステム通知で受け取り、タップすると該当する会話を開きます。スマートフォンで作成したスケジュールタスクは、システムが予定どおりに実行します。
- **会話体験**：ストリーミング返信、添付ファイル、音声入力に対応し、複数のセッションで同時に返信できます。返信はいつでも停止でき、中断した返信の続きを生成したり、返信を再生成したり、送信済みの質問を編集したりできます。
- **ファイル**：他のアプリのファイルやテキストを会話に直接共有でき、会話内のファイルを他のアプリに共有することもできます。
- **すべての管理機能**：Agent、スキル、MCP、ナレッジベース、メモリ、スケジュールタスク、チャネル、ゲストページ、モデルと機能などの設定は Web コンソールと共通で、すべてスマートフォンから管理できます。
- **その他**：多言語の画面表示に対応しています。デバイスの認証情報は iOS のキーチェーンと Android Keystore に保存されます。

Thanks @zkjqd、@a1094174619

## 🔗 デバイス管理

Web コンソール、デスクトップクライアント、モバイルアプリにデバイス管理を追加しました。各クライアントは相互に接続でき、複数のデバイス上の CowAgent を 1 か所から操作できます：

- **ペアリング接続**：「デバイス管理」で「他のデバイスから接続」をクリックすると、QR コードとペアリングコード（有効期限 5 分、1 回のみ使用可能）が生成されます。スマートフォンは QR コードを読み取って接続し、PC はアドレスとペアリングコードを入力して接続します。画面のないサーバーでは `cow pair` を実行すると、ターミナルにペアリングコードと QR コードが表示されます。
- **デバイスの切り替え**：Web コンソール、モバイルアプリ、デスクトップクライアントから他の PC やサーバー上の CowAgent インスタンスに接続し、デバイスを切り替えて操作できます。たとえば、スマートフォンやノート PC からサーバー上の Agent を管理できます。
- **クラウドインスタンス**：[CowAgent Cloud](https://docs.cowagent.ai/ja/guide/cloud) のインスタンスもペアリングで接続できます。スマートフォンで QR コードを読み取れば、ネットワーク環境を問わずいつでもどこでも利用できます。
- **デバイス一覧**：「接続元のデバイス」に接続済みのすべてのデバイスが表示され、接続方法（ペアリング接続またはパスワードでのログイン）と最終アクティブ時刻を確認できます。名前の変更や削除ができ、削除したデバイスは直ちに切断されます。
- **個別の認証情報**：デバイスごとに個別のログイン認証情報を使用し、Agent からは読み取れません。

## 🤖 モデル機能

- **CowAgent モデルサービス**：1 つの API キーで Claude、GPT、Gemini、DeepSeek、Qwen などの主要モデルを利用でき、画像理解、画像生成、音声、ベクトル、Web 検索もカバーします。関連ドキュメント：[CowAgent モデルサービス](https://docs.cowagent.ai/ja/models/cowagent)
- **Codex サブスクリプション**：ChatGPT でログインすると、CowAgent はあなたのアカウントのサブスクリプションを通じて GPT モデルを呼び出します。API キーは不要で、Web コンソールとデスクトップクライアントのどちらからでもログインできます（Thanks @shuaiplus #4019、@6vision #4052）。
- **新モデル**：`gemini-4-neon`（Gemini のデフォルトモデル）、`gemini-4-carbon`、`gemini-4-hydrogen`、`gpt-6.2-sol`（OpenAI のデフォルトモデル）、`gpt-6.2-astra`、`claude-fable-5-2` を追加しました。画像生成には `gpt-image-2.6-flare`、`gpt-image-2.6-sunburst`、`gemini-nano-banana-2.1` を追加しました。
- **音声**：DeepSeek の音声認識と音声合成を追加しました。
- **思考の強度**：Web コンソールのモデル設定で思考の強度を設定できます（Thanks @shuaiplus #4040）。
- **画像理解**：LinkAI の画像理解はデフォルトで `deepseek-flash` を使用し、メインモデルが画像に対応している場合は画像を直接渡します（Thanks @6vision #4048）。
- **安定性**：Claude で複数ターンのツール呼び出しの間も思考内容を保持します。ハートビートしか返さないストリーミング接続は、長時間止まらず時間どおりに終了します（Thanks @c020627 #3892, #3909, #3912、@eric7h #3930）。OpenAI Responses API で `dependentRequired` を含む MCP ツールのパラメーターに対応し、ストリーミングのエラーメッセージを保持します（Thanks @linzch3 #4005, #4006、@Alion548 #4002）。
- **その他**：Gemini が正確な終了理由を返し、リモート画像のダウンロードサイズを制限しました（Thanks @c020627 #3903, #4009）。Kimi K3.1 のコンテキスト長を追加しました（Thanks @JohnQsk #3876）。ModelScope のツール呼び出しにシステムプロンプトを含めます（Thanks @pcbeingused333 #3974）。Chat API で異なるセッションのリクエストが互いにブロックしなくなりました（Thanks @thejesh23 #4034）。LinkAI の会話履歴をコンテキストの予算に合わせて切り詰めます（Thanks @c020627 #3922）。iFLYTEK 音声のいくつかの問題を修正し、音声認識で修正が重なっても古いテキストが残らず、長い音声の末尾も欠けなくなりました（Thanks @c020627 #3899、@MrGendo #3968、@nurlanmnn #4059、@pcbeingused333 #4066）。

## 🔍 Web 検索とページ読み取り

- **検索プロバイダー**：Outcrawl、Firecrawl、SpecStream、Olostep、SearchApi、Context.dev を追加しました。Olostep はページ読み取りのバックエンドとしても使用できます（Thanks @heydryft #3881、@JuampiHernandez #3908、@Specstreamai #3915、@Olostep-devs #3933、@gabsferreira #3936、@mrmps #4018）。
- **ページ読み取り**：追加の依存関係なしで Word と PowerPoint のドキュメントを読み取れるようになり、Web ページ内の画像は Markdown 形式で保持されます。中国語・日本語・韓国語などのページの文字コードを正確に判定し、コードブロックのインデントを保持します（Thanks @tanishqbaweja #3878, #3879, #3882）。Bocha 検索で結果がない場合もエラーにならなくなりました（Thanks @MrGendo #3954）。

## 🖥 デスクトップクライアントと Web コンソール

- **セッションの状態**：セッション一覧に実行状態と未読マークを表示し、送信前の下書きをセッションごとに保存します（Thanks @6vision #3942）。
- **音声入力のショートカット**：デスクトップクライアントで `Cmd/Ctrl + Shift + M` を押すと音声入力を開始・終了でき、リモコンやマウスのサイドボタンなどのデバイスとも組み合わせられます（Thanks @baqideli #4020）。
- **動作の滑らかさ**：長いセッションで返信中に画面が固まる問題と、セッションを切り替えた後に古い画面が残る問題を修正しました。切断されたディスプレイ上にあるウィンドウは自動で表示範囲に戻ります（Thanks @6vision #3919, #3920, #4042）。
- **ナレッジベース**：デスクトップクライアントでナレッジベースのドキュメントを移動、名前変更、削除できるようになりました（Thanks @zkjqd #3859）。
- **ファイル**：送信済みのファイルをアプリ内で直接プレビューできます（Thanks @6vision #4003）。
- **表示**：デフォルトでシステムのライトモードとダークモードに従います。会話のテキストを書かれたとおりに表示し、`(c)`、`..`、引用符などの文字を自動変換しなくなりました（Thanks @tanishqbaweja #3901）。表示名を設定したモデルは元のモデル ID も併せて表示します（Thanks @tanishqbaweja #3866）。デスクトップクライアントの検索プロバイダー一覧に、Zhipu や Qianfan などモデルのキーを共用するプロバイダーを追加しました（Thanks @fanjiahe #3867、@592774447 #3865）。

## 🛡 セキュリティ強化

- **クロスサイトリクエストの防止**：他の Web サイトからの書き込みリクエストを拒否します。パスワードを設定していない場合は、`web_allowed_hosts` でアクセスできるドメインを制限し、DNS リバインディングを防げます（Thanks @failsafesecurity #3789, #3790）。
- **ログイン認証情報**：認証情報をパスワードから切り離し、漏えいした認証情報からパスワードを割り出せないようにしました。クライアント IP は同じマシン上のリバースプロキシから渡されたものだけを信頼し、ログ内のキーとパスワードは自動でマスクされます。
- **脆弱性の修正**：MCP の認可コールバックページの XSS を修正し、画像理解ツールが認証情報のパス保護に従うようにしました。プラグインのインストール、スキル名、管理用パスワードの検証を強化し、コマンドの権限判定の漏れを修正しました（Thanks @MrGendo #3948, #3949, #3950, #3951, #3958, #3959, #3961）。Feishu の長時間接続で TLS 証明書を検証します（Thanks @failsafesecurity #3796）。SSRF 対策の対象をキャリアグレード NAT のアドレス範囲と Feishu の画像リンクに広げました（Thanks @rudycelekli #3913、@c020627 #3916）。コンソールではスクリプト系のファイルをサンドボックスで開きます（Thanks @zkjqd #3938）。
- **リソースと境界**：スキルのダウンロードサイズ、ブラウザのタイムアウト、各種サブプロセスの実行時間を制限しました。ナレッジベースのカテゴリ名と Windows の予約ファイル名を検証し、設定ファイルへの同時書き込みが互いに上書きしなくなりました。Agent の読み込みに失敗しても、他の Agent のデータを読み取ることはありません（Thanks @c020627 #3736, #3824, #3831, #3836, #3886, #3887, #3893, #3894, #3911, #3914, #3921、@eric7h #3928, #3935、@MrGendo #3952, #3955, #3956, #3967）。

## 📦 アップグレード方法

- **ソースデプロイ**：`cow update` でワンクリック更新するか、Web コンソールのサイドバーのバージョンメニューから更新するか、最新コードを取得して再起動します。詳しくは[アップグレードガイド](https://docs.cowagent.ai/ja/guide/upgrade)を参照してください。
- **デスクトップクライアント**：クライアント内で更新を確認してワンクリックで更新するか、[ダウンロードページ](https://cowagent.ai/download/)から最新版を入手できます。
- **モバイルアプリ**：公開ベータ中です。iOS は TestFlight からインストールし、Android はインストールパッケージをダウンロードし、HarmonyOS は Huawei AppGallery の招待テストに参加します。詳しくは[ダウンロードページ](https://cowagent.ai/download/#mobile)と[モバイルアプリのドキュメント](https://docs.cowagent.ai/ja/guide/mobile#ダウンロードとインストール)を参照してください。

アップグレード前の注意点：

- モバイルアプリや他のデバイスから接続する場合、接続先の CowAgent を 2.3.0 以降にアップグレードし、リスンアドレスに他のデバイスからアクセスできる（ローカルのみのリスンではない）必要があります。アクセスパスワードの設定を推奨します。
- 他の Web サイトのページからコンソールの API を呼び出す場合は、そのサイトを `web_allowed_origins` に追加してください。
- Nginx などのリバースプロキシ経由でアクセスする場合は、アクセスアドレスとクライアント IP を正しく識別できるよう、`Host` と `X-Real-IP` ヘッダーを転送してください。
