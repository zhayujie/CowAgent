## 🗂 複数ワークスペース

Agent は単一のディレクトリに縛られなくなり、複数のプロジェクトワークスペースを用意してセッションごとに使い分けられます。Web コンソールとデスクトップクライアントの両方で利用できます：

- **複数ワークスペース**：任意のディレクトリを新規作成または開いてプロジェクトワークスペースにでき、Agent が作る文書・Web ページ・コードなどの成果物はその中で生成・管理されます。
- **セッションごとのワークスペース**：各セッションが自分のプロジェクトワークスペースに紐づくため、複数のタスクを並行して動かしても互いに干渉しません。
- **セッションごとのモデル**：セッション単位でモデルを切り替えられます。新しいセッションはグローバル設定のデフォルトモデルで始まります。
- **セッションのグループ化**：セッション一覧はワークスペースごとにグループ表示され、ピン留め・並べ替え・名前変更・削除に対応します。
- **システムリソースは共通**：メモリ・Skill・ナレッジベースなどは引き続きシステムワークスペース（デフォルトは `~/cow`）に置かれます。

## 🔐 権限モード

セッション単位の権限モードを追加しました。ワークスペースと組み合わせることで、Agent が触れる範囲を柔軟に管理できます：

- **3 段階の権限**：読み取り専用（read-only）、ワークスペース書き込み可（workspace-write）、フルアクセス（full-access）の 3 モードを、セッションごとに設定できます。
- **デフォルト権限**：デフォルトの権限モードを設定でき、新しいセッションはその値で作成されます。
- **クリックできる拒否表示**：権限によってツール呼び出しがブロックされた際、その場で権限を調整できるクリック可能なヒントを表示します。

## 🖥 デスクトップクライアント

- **音声入力**：チャット入力欄に音声入力ボタンを追加し、話した内容を認識してそのまま入力欄に反映します。音声認識と音声合成はカスタムプロバイダーとモデルにも対応します。Thanks @chimyves (#3052, #3050)
- **下書きの保持**：チャット画面を離れて戻っても、未送信のテキストと添付が失われなくなりました。Thanks @chimyves (#3040)
- **ログイン時に自動起動**：システム設定に自動起動のスイッチを追加しました（デフォルトはオフ）。
- **起動診断**：バックエンドの起動に失敗した際、これまでの曖昧なエラーではなく具体的な診断情報を表示します。
- **ログのダウンロード**：実行ログ画面からログファイルをダウンロードできます。ローカルアップロードにはリトライと、より分かりやすいエラー表示を追加しました。

ダウンロード：[CowAgent デスクトップ](https://cowagent.ai/download/)

ドキュメント：[デスクトップクライアント](https://docs.cowagent.ai/ja/guide/desktop)

## 🔔 タスク通知

Agent の実行が完了または失敗したときに、Web とデスクトップの両方で通知（通知音つき）を表示します。長時間のタスクでも進捗に気づけます：

- **両クライアントに対応**：デスクトップは OS 通知、Web はブラウザ通知で知らせます。ウィンドウが非アクティブのときだけ通知し、クリックすると該当セッションに戻ります。
- **未読バッジ**：Web ではタブが非表示のあいだ未読件数をバッジで示し、戻ると解除されます。
- **個別に切り替え可能**：通知本体と通知音は独立したスイッチで、どちらもデフォルトで有効です。自分でキャンセルしたタスクでは失敗通知が出ません。

Thanks @chimyves (#3056, #3055)

## 🤖 モデルの更新

- **新モデル追加**：`glm-5.3`、`qwen3.8-max`、`gemini-3.7-flash`、`gemini-3.6-flash` に対応し、それぞれ各プロバイダーのデフォルトモデルにしました。
- **設定ページの統合**：Web コンソールの「モデル」ページを「設定」ページに統合し、「基本設定」と「モデル設定」の 2 タブに分けて、ページ移動を減らしました。
- **呼び出しの修正**：GLM-5.3 の強制思考、および DashScope の一部モデルのルーティングと API ベース URL の設定に関する問題を修正しました。セッションのモデル選択でカスタムモデルが表示されるようになりました。

## 🛠 改善と修正

- **画像表示**：ローカルパスの画像と、ナレッジ文書内の相対パス画像が表示されない問題を修正しました。デスクトップではチャットや文書の画像をクリックするとその場で拡大できます。Thanks @chimyves (#3046)
- **Windows のドライブ**：Windows でフォルダ選択がドライブ一覧を表示できない問題を修正しました。Thanks @CNXudiandian (#3048)
- **Windows のコマンド案内**：Windows でコマンドが失敗した際の復旧案内を改善しました。Thanks @dajiaohuang (#3065)
- **IM 返信の整理**：IM チャネルの Agent 返信に思考内容が混ざらなくなりました。Thanks @LHMQ878 (#3044)
- **定期タスクの修正**：日付をまたいで失敗したあとスケジュールに復帰しない問題（Thanks @chimyves #3054）と、定期タスクが実行されずに確認応答だけ返る問題を修正しました。
- **初回対話の高速化**：記憶システムの初期化フローを最適化し、セッション最初のメッセージをブロックしなくなりました。初回対話の待ち時間が大幅に短縮されます。
- **コンテキストの切り詰め**：コンテキストが切り詰められた際に AI の返信が保存されない問題を修正しました。
- **Feishu チャネル**：ストリーミングカードで複数ターンのテキストを蓄積して表示できるようになりました。
- **Docker**：`COW_DATA_DIR` のマウントにより、コンテナのアップグレードをまたいで `config.json` が保持されます。

## 📦 アップグレード方法

- **ソースデプロイ**：`cow update` でワンクリック更新するか、最新コードを取得して再起動します。詳しくは[アップグレードガイド](https://docs.cowagent.ai/ja/guide/upgrade)を参照してください。
- **デスクトップクライアント**：クライアント内で更新を確認してワンクリックで更新するか、[ダウンロードページ](https://cowagent.ai/download/)から最新版を入手できます。
