**CowAgent** は、自律的なタスク計画、長期記憶、Skill システム、マルチモーダルメッセージ、複数モデル対応、マルチプラットフォームデプロイを備えた、LLM を活用した AI スーパーアシスタントです。

CowAgent は自ら思考しタスクを計画し、コンピュータや外部リソースを操作し、Skill を作成・実行し、長期記憶により継続的に成長します。複数モデルの柔軟な切り替えをサポートし、マルチエージェントチームを素早く構築でき、テキスト、音声、画像、ファイルなどのマルチモーダルメッセージを処理でき、WeChat、Web、Feishu（飛書）、DingTalk（釘釘）、WeCom（企業微信）、WeChat公式アカウントに統合できます。お使いのパソコンやサーバー上で24時間365日稼働します。

## クイック体験

ターミナルで以下のコマンドを実行すると、ワンクリックでインストール、設定、起動ができます：

<Tabs>
  <Tab title="Linux / macOS">
    ```bash
    bash <(curl -fsSL https://cdn.link-ai.tech/code/cow/run.sh)
    ```
  </Tab>
  <Tab title="Windows (PowerShell)">
    ```powershell
    irm https://cdn.link-ai.tech/code/cow/run.ps1 | iex
    ```
  </Tab>
  <Tab title="Docker">
    ```bash
    curl -O https://cdn.link-ai.tech/code/cow/docker-compose.yml
    docker compose up -d
    ```
  </Tab>
</Tabs>

デフォルトでは実行後に Web サービスが起動します。`http://localhost:9899/chat` にアクセスして Web インターフェースでチャットできます。

デスクトップクライアント（macOS / Windows）も利用できます。Agent の実行環境を内蔵しており、[ダウンロード](https://cowagent.ai/download/)してすぐに使えます。

スマートフォンでは CowAgent アプリ（iOS / Android / HarmonyOS、公開ベータ版）を使い、スマートフォン上で直接 Agent を実行するか、QR コードで PC やサーバー上の CowAgent に接続できます。詳しくは [モバイルアプリ](/ja/guide/mobile) を参照してください。

自分でデプロイしたりモデルのキーを用意したりしたくない場合は、[オンラインで利用](https://cloud.cowagent.ai/?utm_source=docs)することもできます。ブラウザで専用インスタンスを作成でき、モデルサービスを内蔵し、24 時間 365 日稼働します。詳しくは [CowAgent Cloud](/ja/guide/cloud) を参照してください。
