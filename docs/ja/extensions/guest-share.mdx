> Agent を独立したチャットページとして公開したり、自分の Web サイトに埋め込んだりできます。製品に関する質問対応、ドキュメント Q&A、カスタマーサポートなどに向いています。訪問者はリンクを開くだけで、ログインなしで会話できます。

ゲストページの Agent は、普段使っている Agent とは切り離されています。そのページに開放したツール、スキル、参考資料だけを使い、あなたのメモリ、会話、ワークスペースは見えません。

## 有効化

「設定 → 連携設定 → ゲストページ」でスイッチをオンにします。

- **先にコンソールのパスワードを設定してください。** ゲストページはコンソールと同じポートを使うため、パスワードが未設定の間はリンクにアクセスできません。設定すると自動的に公開されます。
- **外部からアクセスできる必要があります。** デプロイ方法は [Web コンソール](/ja/channels/web) を参照してください。ドメインやパブリック IP で公開する場合は、同じページの「アクセスアドレス」に公開アドレスを入力すると、共有リンクと埋め込みコードにそのアドレスが使われます。

## ページの作成

「新規ゲストページ」をクリックし、入力して保存するとリンクが発行されます。

### 基本情報

名前、モデル、ウェルカムメッセージ、おすすめの質問。モデルを選ばない場合はグローバルの既定モデルを使います。おすすめの質問はウェルカム画面に表示され、訪問者はクリックして質問できます。

### 外観

アイコンとテーマカラー。ページと埋め込みのチャットボタンに使われます。

### アクセス制御

- **パスワード**：有効にすると、訪問者はパスワードを入力してから利用します。
- **1 人 1 日あたりの質問数**：訪問者はブラウザ単位で区別されます。既定は 100、0 で無制限です。
- **有効期限**：期限を過ぎるとリンクは無効になります。空欄なら無期限です。

### その他の設定

- **ツール**：ファイルの読み書き、ファイル検索、ファイル送信、Web 検索、Web ページの取得、画像理解、現在時刻。新しいページではすべて有効です。ゲストページではコマンドを実行できません。
- **スキル**：インストール済みのスキルから選びます。コマンドやスクリプトに依存するスキルはゲストページでは動かないため、一覧に表示されません。
- **参考資料**：Agent が参照できるフォルダ（読み取り専用）。ナレッジベースやそのカテゴリを選ぶか、任意のフォルダを入力します。「製品ドキュメント、機能や価格の質問に使う」のような短い説明を付けると、Agent がいつ参照すべきか判断しやすくなります。
- **ゲストルール**：Agent のシステムプロンプトに書き込まれます。役割、対応範囲、返答のスタイルなどを書きます。
- **フッター**：ページ下部の文言とリンク。変更や削除ができます。

## 共有と埋め込み

ページ一覧からリンクをコピーして共有します。リンクは `https://<アクセスアドレス>/share/<token>` の形式です。

Web サイトに埋め込むには、ページの「Web ページに埋め込む」をクリックし、「埋め込みを許可するサイト」に自分のサイト（例：`https://example.com`）を追加してから、コードを Web ページの `<body>` 内に配置します。右下にチャットボタンが表示されます。ダイアログ内で埋め込み後の見た目をそのまま確認できます。

```html
<script src="https://agent.example.com/assets/guest/embed.js"
  data-share-url="https://agent.example.com/share/<token>"
  data-title="お問い合わせ"
  defer></script>
```

`data-color` でボタンの色を、`data-position="left"` でボタンを左下に変更できます。

## ページの管理

- **訪問者の記録**：訪問者ごとの会話を確認できます。
- **リンクをリセット**：新しいリンクを発行し、旧リンクと埋め込みコードは直ちに無効になります。
- **すべての訪問者を切断**：全員が入り直す必要があります（パスワード付きのページでは再入力が必要です）。以前の会話は表示されなくなります。
- **停止 / 再開**：停止中はリンクが使えず、進行中の応答も中断されます。
- **削除**：ページ、リンク、すべての訪問者の記録を削除します。元に戻せません。

## セキュリティ

- ゲスト Agent が使えるのは、現在の会話の一時フォルダと、選択した参考資料・スキルだけです。実際のパスは見えず、これらのフォルダの外には出られません。
- コマンドは実行できません。ネットワーク系ツールはインターネット上の公開アドレスにのみアクセスでき、ローカルや社内ネットワークのアドレスはブロックされます。
- ページの設定は `~/cow/guests/<ページ ID>/` に保存されるため、自分の Agent に変更を頼むこともできます。ツールや参考資料の追加、ネットワークの有効化、パスワードの解除など権限を広げる変更は、コンソールで「確認して反映」をクリックするまで反映されません。
